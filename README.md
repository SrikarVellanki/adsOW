# adsOW business website

A responsive, static one-page website for adsOW, using the supplied logo and delivery-rider concept image.

## Files
- `index.html` — page content and SEO metadata
- `styles.css` — responsive layout, black/yellow/cream theme, transitions, and reduced-motion support
- `script.js` — mobile navigation, scroll reveals, footer year, and email enquiry form
- `assets/adsow-logo.jpg` — supplied adsOW logo
- `assets/rider-ad-mockup.png` — supplied concept mockup

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or serve the folder using VS Code Live Server.
3. No build step or package installation is required.

## Contact form
The form uses a `mailto:` link to prepare an email to `vellanki.srikar@gmail.com`. It does not send or store submissions on its own. For reliable submissions without the visitor's email app, connect a form service or a backend before launch.

## Before publishing
- Confirm campaign wording, business email, privacy policy, and any legal/operational claims.
- The website intentionally describes adsOW as pre-revenue/pre-pilot; no active coverage or guaranteed campaign availability is claimed.
- Confirm permissions and any platform/branding requirements before using a rider or delivery-bag ad in a live campaign.
- Google Fonts are loaded from Google Fonts; if offline use is needed, replace them with local fonts.
